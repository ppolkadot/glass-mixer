# Glass Mixer 0.3.0

Release date: 2026-10-18. Candidate branch: `experiments`.

Glass Mixer 0.3.0 carries forward the 0.2.0 beta feature set and the final
review corrections. See [CHANGELOG.md](../../CHANGELOG.md) for the feature,
fix, upgrade and downgrade details.

## Downloads

The GitHub Release should include both packages:

- `glass-mixer-0.3.0-portable.zip` — portable executable and README.
- `glass-mixer-0.3.0-setup.exe` — per-user Inno Setup installer; no admin
  rights required.

Both packages are unsigned unless a signing certificate is configured.
