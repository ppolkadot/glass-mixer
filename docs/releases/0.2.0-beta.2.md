# Glass Mixer 0.2.0-beta.2 — second beta

Date: 2026-10-18. Source branch: `experiments`.

This beta adds independent output and input device controls, read-only sound
properties, opt-in global shortcuts, app pins, volume presets with conservative
per-process start rules, tray warnings, and a Direct3D 12 / Vulkan fallback
renderer. It includes the follow-up fixes for settings migration, accessibility,
shortcut cleanup, and process tracking described in [CHANGELOG.md](../../CHANGELOG.md),
plus the final review corrections: the Linux-only glib advisory is removed from
the lockfile, hidden in-window warnings keep their remaining display time, and
the posted-message shortcut pressure test runs without owning a global chord.

## Verification and limits

Local formatting, PowerShell syntax, clippy, tests, release compilation and
installer compilation passed for beta.2, and hosted Windows CI run
`#39094235224` passed for commit `e47b328`. The release executable and installer
report product version `0.2.0-beta.2`. See [TESTING.md](../TESTING.md) for
counts and historical hardware/UI checks. The final review corrections were
verified locally and need a fresh hosted run after push.

Upgrading the installer from 0.1.0, real audio changes on varied hardware,
physical shortcut injection, Narrator, Windows 10, and natural OpenGL failure
remain unverified. See [CHANGELOG.md](../../CHANGELOG.md) for upgrade and
downgrade guidance and the full limitations list.
