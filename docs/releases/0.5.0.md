Candidate build of 2026-11-06 from the `experiments` branch. **Not yet published:** no
tag or GitHub release exists. The hashes below are of the local candidate; the
published files' checksums are the ones in the release's `SHA256SUMS.txt`.

app names and pin order, settings export and import, a diagnostic report, the
embedded Polaris typeface, and release tooling. Full details:
[CHANGELOG.md](../../CHANGELOG.md).

## Verification

Recorded in [TESTING.md](../TESTING.md) (Stage 6): format, lint, 194 unit tests and the
real-device tests passed; `package.ps1` and `verify-package.ps1` passed; the installer
lifecycle test passed all 32 checks. What was not tested is listed in
[VALIDATION_MATRIX.md](../VALIDATION_MATRIX.md): Windows 10, USB and Bluetooth audio,
several monitors and mixed DPI, sleep and resume, Explorer restart, and the GitHub
Actions workflows. The overlay and flyout surfaces were not built in this version.

## Upgrade notes

Install over an existing per-user installation, or replace the extracted portable files.
Settings stay compatible with 0.4.0 and are migrated forward. Installations older than
0.4.0 may be left running at the upgrade, because those versions cannot be asked to exit;
close Glass Mixer first.
