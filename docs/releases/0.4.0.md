# Glass Mixer 0.4.0

Release date: 2026-10-20. Delivery branch: `experiments`, merged into `main`.

This release hardens the native Windows tray mixer after the 0.3.0 audit and
final review. Existing mixer controls, presets, pins, shortcuts, notifications
and the OpenGL/wgpu renderer fallback carry forward from 0.3.0.

## Highlights

- Pause level meters under CPU software rendering to keep controls responsive.
  The saved meter preference is retained; Settings explains the limitation.
- Bound icon-worker shutdown to two seconds and discard queued lookups.
- Read UTF-8 BOM and UTF-16 settings. Preserve original migration and damaged
  files byte for byte, and refuse saves after a failed startup read until a
  successful reload. Failed backups leave the original untouched.
- Shut down only the executable in the installation folder during uninstall.
  Discover windowless processes, handle a missing exit listener, and verify the
  executable path on the process handle before any forced termination.
- Filter endpoint property notifications and open Explorer by its full path.
- Include application and dependency licenses in both packages. CI checks
  Windows builds/tests, Rust 1.95 compatibility, and dependency advisories.

Full details: [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

Install over the existing per-user installation, or replace the extracted
portable files. Settings remain at schema version 4; existing 0.3.0 preferences
are supported. Close Glass Mixer before replacing portable files. If startup
cannot read settings, resolve the file lock or access problem and restart before
expecting preference changes to persist. Retain any recovery backups.

## Verification and remaining coverage

Local checks on the final source passed: `cargo fmt --check`,
`cargo clippy --locked --all-targets -- -D warnings`, `cargo test --locked`,
PowerShell syntax parsing, `git diff --check` and `scripts/package.ps1`.
There were 112 passing library tests, 3 passing binary tests and 1 passing
encoding test; 3 desktop-shortcut and 8 hardware tests were ignored.

Live exit checks passed with OpenGL and wgpu, both visible and minimized.
Each target exited cleanly while the copy in another folder remained running.
The independent review found no remaining merge blockers. Packages were built
with Rust 1.99.1 and Inno Setup 6.7.3; notices cover 170 crates and 125 distinct
license texts. Hosted CI run links are recorded in the GitHub Release.

Not exercised in the final correction pass: an actual installed upgrade and
uninstall, Windows 10, the hardware audio matrix, and a new Narrator session.
The process-exit checks do not substitute for installed upgrade/uninstall
coverage. See [TESTING.md](../TESTING.md) for the complete verification history.
